TOURAYS FITNESS V12.2 — INDEPENDENT DEMO PROFILES

This build adds private, browser-local demo profiles without a backend.

- Existing owner data is automatically migrated into the owner local profile.
- A new browser/device starts with a fresh profile and onboarding screen.
- All Tourays localStorage keys are isolated by a unique local profile ID.
- Settings includes Reset demo profile and Create another local profile.
- No Firebase, Supabase, email login, or external database is used.
- Cache and asset versions updated to V12.2.
