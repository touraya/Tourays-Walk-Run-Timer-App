TOURAYS FITNESS V12.4
Indoor Categories + Lock-Screen Workout Controls

Included:
- Finished and strengthened the Indoor Trainer category navigation.
- Category buttons now work reliably on touch devices and stay accessible while browsing.
- Added a smooth horizontal mobile category bar with clear active state.
- Fixed the screen wake-lock logic so it also works during Indoor workouts.
- Added Media Session lock-screen information for Walk/Run and Indoor workouts.
- Lock screen can show the current phase/exercise and remaining time where the browser supports it.
- Added lock-screen pause/resume, next, previous and stop handlers where supported.
- Improved timer recovery when the browser temporarily suspends in the background.

Important mobile note:
Browser and operating-system restrictions still decide exactly which lock-screen controls are shown. The workout timers now restore themselves from real timestamps after returning to the app.
